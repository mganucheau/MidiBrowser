Pattern “Variations” snapshots + morph
What: Let users save multiple pattern states (comp layout + transpose params + loop + humanize) as A/B/C… and morph between them over bars (e.g., 0→100% over 8 bars).
Newness: Variations exist in sequencers, but morphing a comped multi-lane arrangement + scale mapping + timing/velocity in one macro is uncommon in MIDI FX devices. This feels closer to “scene morphing” in synths than typical MIDI tools.

Scale-aware chord intelligence (progression tools)
What: Generate chord progressions from the Main lane’s note distribution; suggest functional substitutions; constrain to selected scale; one-click reharmonize while preserving rhythm.
Newness: Many chord tools exist, but combining analysis of imported MIDI + comped output + constraint-based reharmonization in a single device is less common than standalone chord generators.

Rhythm “style transfer” (MIDI groove from reference)
What: Drop a reference MIDI clip; PatternFlow extracts rhythmic feel (onset histogram, swing, density curve) and applies it to Main while preserving pitches (or vice versa).
Newness: Groove extraction exists (Ableton grooves, MPC), but bidirectional style transfer on MIDI (rhythm ↔ pitch) with controllable strength is still relatively rare in mainstream MIDI FX.

6) Arrangement macros: “Fill”, “Break”, “Build” as timeline functions
What: Buttons that intelligently create fills/breaks/build-ups by editing Main: density ramps, octave lifts, snare roll timing, velocity curves, etc., over a selected range.
Newness: Producers do this manually; some generators do it globally. A range-based, DAW-like edit macro system for MIDI is not crowded.

1) PatternFlow “Scenes” (timeline presets)
What: Save/recall complete states (session length, grid, loop, comp segments, transpose params, lane mutes/solos) as scenes and switch on bar boundaries.
Newness: Scene recall exists in grooveboxes; scene recall for a comped multi-lane MIDI arrangement inside a plugin is uncommon.

10) Intent: Chaos ↔ Control
What: A meta-macro that crossfades multiple underlying processes: quantize strength, motif lock, density, velocity variance, and harmonic tension.
Why uncommon: This is “perform the generator” with one knob—common in synths, rare in MIDI tools done coherently.

8) Ornament Rate
What: Adds ornaments (grace notes, turns, approach tones) at a controllable rate, adapting to density so it doesn’t overfill.
Why uncommon: Ornamentation is typically a generator feature, not a continuous performance macro.

7) Voice Leading Strictness
What: For chordal parts, controls how much notes are allowed to jump between chords (strict = minimal movement, loose = bigger leaps).
Why uncommon: Most MIDI FX don’t expose voice-leading quality as a real-time parameter.
